    Integração com automação (Zapier · Make · n8n · Power Automate)
    Este painel exibe uma simulação do rastreio diário: como artefatos HTML não têm agendador próprio, a checagem às 8h precisa ser disparada por uma automação externa. As publicações carregadas aqui são reais — coletadas diretamente das 6 fontes monitoradas — e cada link leva exatamente à página onde a publicação foi divulgada. "Simular rastreio" só reordena a data de detecção como se o rastreio tivesse ocorrido agora; a data de publicação e o link de cada item permanecem os originais. A estrutura de dados abaixo é normalizada e pronta para ser gerada por uma automação real e consumida por este mesmo painel (via exportação JSON) ou por outra ferramenta interna. 
    {
  "id": "string",
  "dataPublicacao": "YYYY-MM-DD",
  "dataDeteccao": "YYYY-MM-DDTHH:mm:ssZ",
  "fonteId": "esocial-noticias | credito-trabalhador | fgts-digital | fgts-digital-faq | esocial-faq | dou",
  "orgao": "string",
  "titulo": "string",
  "secao": "Seção 1 | Seção 2 | null",
  "url": "string",
  "resumo": "string (2-3 linhas, impacto para o DP)",
  "tipo": "legislacao | norma | procedimento | noticia",
  "prioridade": "alta | media | baixa",
  "palavrasChave": ["string"],
  "status": "novo | lido | arquivado"
}
    Sugestão de fluxo: agendar a automação para 8h → raspar/consultar as 6 fontes → aplicar o filtro de órgãos e palavras-chave do Diário Oficial → gravar os registros novos neste formato → importar via "Exportar/Importar JSON".
